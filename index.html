01 / TEXT GLOW

Make the type glow.

Subtle light can make a headline feel dramatically more premium without adding visual clutter.

HTML + CSS
<h1 class="glow">Lumen</h1>

<style>
.glow {
  color: white;
  text-shadow:
    0 0 18px rgba(255,255,255,.28),
    0 0 55px rgba(150,120,255,.35);
}
</style>

06 / MOUSE SPOTLIGHT

Move around.

The light follows your cursor.

JAVASCRIPT
const card = document.querySelector(".card");

card.addEventListener("pointermove", (e) => {
  const r = card.getBoundingClientRect();
  card.style.setProperty("--x", `${e.clientX - r.left}px`);
  card.style.setProperty("--y", `${e.clientY - r.top}px`);
});
