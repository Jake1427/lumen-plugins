# Lumen Plugins Website

A cinematic, animated GitHub website for showcasing Lumen AI plugin examples.

## Files

- `index.html` — page structure and examples
- `style.css` — visual design, responsive layout, transitions, effects
- `script.js` — scroll reveals, horizontal-scroll activation, cursor effects, and Copy Me buttons

## Run it

Open `index.html` in a browser. No build step is required.

The site links users to [Lumen.baby](https://lumen.baby) and includes copyable HTML/CSS/JS examples that can be adapted into Lumen plugins.

## Customize

Add more example cards in `index.html`, then add the matching snippet to the `code` object in `script.js` so its **Copy Me** button works.
